## Описание

**TODO Tracker** — расширение для Visual Studio Code, которое находит в проекте
заметки-напоминания в комментариях (`TODO`, `FIXME`, `HACK`), собирает их в одну
панель и помогает быстро к ним переходить.

## Возможности

- **Панель «TODO Tracker»** в проводнике: все заметки сгруппированы по файлам, клик по заметке открывает файл на нужной строке.
- **Счётчик в строке состояния** — общее число найденных заметок; клик открывает панель.
- **Подсветка** ключевых слов прямо в редакторе (и на полосе прокрутки).
- **Команда «TODO Tracker: Сканировать рабочую область»** — ручной запуск поиска (также кнопка обновления в заголовке панели).
- **Команда «TODO Tracker: Добавить TODO-комментарий»** (`Ctrl+Alt+T`, на Mac `Cmd+Alt+T`) — вставляет комментарий нужного типа ниже текущей строки с учётом языка (`//`, `#`, `<!-- -->`, `/* */`).
- **Автоматическое обновление** списка при сохранении файла.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `todoTracker.keywords` | `["TODO","FIXME","HACK"]` | Искомые ключевые слова |
| `todoTracker.include` | популярные расширения файлов | Какие файлы сканировать |
| `todoTracker.exclude` | `node_modules, out, dist, build, .git` | Что пропускать |
| `todoTracker.maxFiles` | `2000` | Лимит файлов за один проход |
| `todoTracker.scanOnSave` | `true` | Пересканировать при сохранении |
| `todoTracker.highlight` | `true` | Подсвечивать слова в редакторе |

## Установка и запуск

Требуется Node.js 18.19+ и VS Code 1.90+.

```bash
git clone https://github.com/USERNAME/todo-tracker-lab.git
cd todo-tracker-lab
npm install
npm run compile
```

Откройте папку в VS Code и нажмите **F5** — запустится окно *Extension Development Host* с подключённым расширением. Для проверки откройте папку `samples`.

### Упаковка в .vsix

```bash
npm install -g @vscode/vsce
vsce package
```

Установка: *Extensions → … → Install from VSIX…*
